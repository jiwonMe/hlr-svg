Everything is imported from the package root.

```typescript
import { Scene, Camera, SvgRenderer, Sphere, Vec3 } from "hlr";
import type { RenderOptions, SvgStyle, CubicBezier3 } from "hlr";
```

## Scene

### Scene

```typescript
class Scene {
  constructor(primitives?: readonly Primitive[]);
  readonly primitives: readonly Primitive[];
  add(...primitives: Primitive[]): this;
  removeById(id: string): this;
  clear(): this;
  toRaycastScene(camera: Camera, profiler?: Profiler, preparedGeometry?: boolean): RaycastScene;
}
```

`toRaycastScene` builds a ray-casting scene for that camera. The returned object has these two methods.

```typescript
visibleAtPoint(p: Vec3, opts?: { eps?: number; ignorePrimitiveIds?: readonly string[] }): boolean;
raycastClosest(
  ray: Ray,
  opts?: { tMin?: number; tMax?: number; ignorePrimitiveId?: string; ignorePrimitiveIds?: readonly string[] },
): Hit | null;
```

`preparedGeometry: true` prepares fast intersection kernels for built-in shapes. Rebuild it when the shapes change.

## Camera

```typescript
class Camera {
```


## Shapes

### Primitive, Ray, Hit

```typescript
interface Primitive {
  readonly id: string;
  intersect(ray: Ray, tMin: number, tMax: number): Hit | null;
}
```

### Analytic shapes

```typescript
class Sphere { constructor(id: string, center: Vec3, radius: number) }

class Cylinder {
  constructor(id: string, base: Vec3, axis: Vec3, height: number, radius: number, caps?: CylinderCaps);
  readonly axis: Vec3; // normalized
}
type CylinderCaps = "none" | "both"; // default "both"

class Cone {
  constructor(id: string, apex: Vec3, axis: Vec3, height: number, baseRadius: number, cap?: ConeCaps);
  readonly axis: Vec3; // apex → base, normalized
}
type ConeCaps = "none" | "base"; // default "base"

class BoxAabb { constructor(id: string, min: Vec3, max: Vec3) }

class OrientedBox {
  constructor(id: string, center: Vec3, halfSize: Vec3, axisX: Vec3, axisY: Vec3);
  readonly axes: readonly [Vec3, Vec3, Vec3]; // orthonormal, z = x × y
  toLocal(p: Vec3): Vec3;
  corners(): Vec3[]; // 8
  edges(): [Vec3, Vec3][]; // 12
  faces(tag?: string): PlaneRect[]; // 6, ids `${id}:${tag}:face:±x|±y|±z`
}

class PlaneRect {
  constructor(id: string, center: Vec3, normal: Vec3, uHint: Vec3, halfWidth: number, halfHeight: number);
  readonly normal: Vec3; // unit
  readonly u: Vec3; // uHint projected onto the plane, normalized
  readonly v: Vec3; // normal × u
}

class Disk { constructor(id: string, center: Vec3, normal: Vec3, radius: number) }
```

Constructor arguments are also exposed as read-only properties of the same name (`sphere.center`, `cone.baseRadius` and so on).

`RaycastScene` is the object returned by `scene.toRaycastScene(camera)`. For straight curves,
`splitLineCubicByVisibilityAdaptive` scales its samples to the on-screen length and is faster.
