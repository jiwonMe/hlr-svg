## Install

`hlr` is a TypeScript library published as an ES module. It has no dependencies and runs the same
in Node.js 20+ and in browser apps built with a bundler (Vite, webpack, esbuild and so on).

```bash
pnpm add hlr
# or npm install hlr / yarn add hlr
```

> The package is `"type": "module"`. From CommonJS (`require`), load it with `await import("hlr")`.

## A first figure: a sphere on a plane

Let's draw a figure that math exams use all the time: a sphere sitting on plane α. The part of the
sphere below the plane and the lines behind the sphere come out dashed.

```typescript
import { writeFileSync } from "node:fs";
import { Camera, PlaneRect, Scene, Sphere, SvgRenderer, Vec3 } from "hlr";

// 1. The scene: give every shape a unique id.
const scene = new Scene([
  new Sphere("S", new Vec3(0, 1, 0), 1.5),
  new PlaneRect(
    "alpha",
    new Vec3(0, 0, 0), // center
    new Vec3(0, 1, 0), // normal (up)
    new Vec3(1, 0, 0), // width direction
    3, // half width
    3, // half height
  ),
]);

// 2. The camera: exam figures suit orthographic projection, where parallel lines stay parallel.
const width = 640;
const height = 480;
const camera = Camera.from({
  kind: "orthographic",
  position: new Vec3(6, 5, 8),
  target: new Vec3(0, 0.6, 0),
  up: new Vec3(0, 1, 0),
  halfHeight: 3, // half the screen height, in world units
  aspect: width / height,
  near: 0.1,
  far: 100,
});

// 3. Render: the result is an SVG string.
const renderer = new SvgRenderer({ width, height });
const svg = renderer.render(scene, camera);

writeFileSync("figure.svg", svg);
```

Run it with `node figure.mjs` and you get `figure.svg` with three kinds of lines:

- **The sphere's outline**: its rim as seen from the camera. The part below the plane is hidden by the plane, so it is dashed.
- **The plane's border**: four edges. Where they pass behind the sphere they are dashed.
- **The intersection curve**: the circle where the plane cuts the sphere. Its far half is dashed.

[Core concepts](/docs/en-us/concepts) explains where these lines come from and how they are split
into visible and hidden parts.

## In the browser

The result is a string, so put it straight into the DOM.

```typescript
const svg = renderer.render(scene, camera);
document.querySelector("#figure")!.innerHTML = svg;
```

When the view changes, create a new camera with `Camera.from` and render again with the same
`SvgRenderer`. The renderer remembers camera-independent work (intersection curves), so redrawing is fast.

## Line style

`style` sets visible and hidden lines separately. Here is a setting close to exam figures.

```typescript
const renderer = new SvgRenderer({
  width,
  height,
  background: false, // no white background rectangle
  style: {
    strokeVisible: "#0a0a0a",
    strokeHidden: "#0a0a0a",
    strokeWidthVisible: 1.4,
    strokeWidthHidden: 1.1,
    dashArrayHidden: "3.2 2.6",
    opacityHidden: 0.9,
  },
});
```

To drop hidden lines entirely use `opacityHidden: 0`; to draw them solid use `dashArrayHidden: "none"`.
Every option is listed in [Rendering and styles](/docs/en-us/rendering).

## Several shapes

With several shapes, occlusion between them and their intersection curves are computed automatically.

```typescript
import { BoxAabb, Cone, Cylinder, Scene, Sphere, Vec3 } from "hlr";

const scene = new Scene([
  new Sphere("ball", new Vec3(-1.6, 1, 0), 1),
  new Cylinder("can", new Vec3(0, 0, 0), new Vec3(0, 1, 0), 2, 0.7),
  new Cone("cone", new Vec3(1.6, 2, 0), new Vec3(0, -1, 0), 2, 0.9),
  new BoxAabb("box", new Vec3(-0.5, 0, 1), new Vec3(0.5, 1, 2)),
]);
```

`Cylinder` takes a base center, an axis direction, a height and a radius; `Cone` takes an apex, an axis
(from the apex toward the base), a height and a base radius. See [Primitives](/docs/en-us/primitives).
