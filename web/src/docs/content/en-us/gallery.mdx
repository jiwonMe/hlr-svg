Every figure in the [example gallery](/docs/en-us/examples) is rendered live in your browser by hlr.
Drag to orbit, scroll to zoom, and switch how hidden lines are drawn (dashed, removed, solid). Each example
comes with the full code that draws it, ready to copy and run.

## Exam figures

| Example                              | What to look for                                             |
| ------------------------------------ | ------------------------------------------------------------ |
| Plane ABC and the coordinate axes    | a face hiding the axes, so their far parts turn dashed       |
| Section of a cube                    | edges, a triangular section and point names                  |
| Cylinder cut at 45°                  | the ellipse where a plane cuts a cylinder                    |
| Three spheres tangent to a sphere    | several spheres and two planes hiding each other, plane sections |
| Sphere and two plane sections        | two planes through a sphere and the circles they cut         |

## Library features

| Example                       | What to look for                                                |
| ----------------------------- | --------------------------------------------------------------- |
| Simple primitives             | outlines of a sphere, cylinder, cone and box, and where they meet |
| Conic section (Plane × Cone)  | the section becomes a circle, ellipse, parabola or hyperbola as the plane tilts |
| Random primitives (seeded)    | rebuilding the same scene from the same seed                    |
| OBJ/STL mesh import           | drop a file and see mesh feature edges with hidden lines        |

Examples with shading let you change the light direction and ambient light. Shading uses the surface
buffer API from [Surface shading](/docs/en-us/shading).
