[도형 작업실](/playground)은 이 라이브러리로 만든 3차원 편집기입니다. 화면에 보이는 선이 곧
내보내는 SVG입니다. 작업은 브라우저에 자동 저장됩니다.

## 화면 구성

- **왼쪽 위 · 만들기**: 도형(구·원기둥·원뿔·직육면체·평면·원판), 점·선분·면, 작도, 불리언, 표시 도구.
- **왼쪽 아래 · 장면**: 모든 개체 목록. 불리언 결과 아래에 재료가 들여 쓰여 있습니다.
- **가운데 · 뷰포트**: 위에 변형 도구·스냅·시점·투영 단추, 아래에 상태 표시줄.
- **오른쪽 · 속성**: 고른 개체의 값. 아무것도 고르지 않으면 장면 설정(선 모양, 라벨, 채색).

## 시점 다루기

| 동작                          | 결과                         |
| ----------------------------- | ---------------------------- |
| 빈 곳 끌기                    | 궤도 회전                    |
| Shift·오른쪽·가운데 단추 끌기 | 화면 이동                    |
| 휠, 두 손가락 오므리기        | 커서 쪽으로 확대·축소        |
| `0` `1` `3` `7`               | 등각·정면·옆면·윗면 시점     |
| `5`                           | 직교 ↔ 원근                  |
| `F`                           | 고른 것(없으면 전체)에 맞춤  |

## 고르기

- 도형을 누르면 고릅니다. **같은 자리를 다시 누르면 그 뒤에 있는 도형**으로 넘어갑니다.
- **Shift(또는 ⌘·Ctrl)+누르기**로 여럿을 고르고 뺍니다. 고른 순서가 기억되어 불리언(A, B)과
  각(A, 꼭짓점, B)에 쓰입니다. 속성 패널에 번호와 함께 나옵니다.
- `⌘A`는 전체 선택, `Esc`는 선택 해제입니다.
- 장면 목록에서는 ⌘·Ctrl+누르기로 하나씩, Shift+누르기로 범위를 고릅니다. 두 번 누르면 이름을 바꿉니다.

## 옮기기 · 돌리기 · 크기

| 도구        | 키  | 손잡이                                                                           |
| ----------- | --- | -------------------------------------------------------------------------------- |
| 이동        | `W` | X·Y·Z 화살표는 그 축으로, 바닥의 작은 사각형은 수평면 위로, 가운데 상자는 화면 평면으로 |
| 회전        | `E` | X·Y·Z 축 둘레의 고리                                                             |
| 크기        | `R` | 점선 원·가운데 상자는 같은 비율로, 축 끝 상자는 그 방향 치수만                    |

- **스냅**(0.1 ~ 1)을 켜면 위치는 그 간격, 회전은 15°, 크기는 0.05 단위로 맞습니다. `⌥`(Alt)를 누르는
  동안은 스냅이 꺼집니다.
- 여럿을 고르면 가운데를 기준으로 함께 옮기고 돌리고 키웁니다.
- 방향키는 스냅 간격만큼 옮깁니다(Shift+↑↓는 위아래).
- 크기 손잡이: 직육면체는 각 변, 원기둥·원뿔은 Y가 높이·X/Z가 반지름, 평면은 가로·세로입니다.

## 점 찍기와 붙이기

**점**(`P`)을 누르면 찍기 모드가 됩니다. 미리보기 점과 이름표가 커서를 따라다니고, 누른 자리에 점이
생깁니다. 끌면 평소처럼 시점이 돌아가고, `Esc`나 `P`를 누르면 끝납니다.

새 점은 커서 아래에 있는 것에 붙고, 붙은 것을 따라 움직입니다.

| 커서 아래                                                  | 새 점                                         |
| ---------------------------------------------------------- | --------------------------------------------- |
| 이미 있는 점                                               | 새로 만들지 않고 그 점을 고름                 |
| 직육면체·평면의 꼭짓점, 원뿔의 꼭짓점, 원기둥·원뿔 밑면의 중심 | 그 자리에 고정 (□)                            |
| 구·원판·평면의 중심                                        | 중심 (○)                                      |
| 선분의 가운데                                              | 중점 (△)                                      |
| 선분                                                       | 선분 위의 점. 1 : 2, 2 : 1, 1 : 3, 3 : 1에서 걸림 (×) |
| 구·평면·원판                                               | 구 위·평면 위·원판 위의 점 (◇)                |
| 그 밖의 겉면                                               | 그 자리의 자유 점 (점선 ◇)                    |
| 빈 곳                                                      | 바닥(y = 0) 격자 위의 자유 점 (+)              |

- 이름표가 무엇에 붙는지 알려 주고, 붙을 도형은 초록으로 강조됩니다.
- `⌥`(Alt)를 누르고 찍으면 아무것에도 붙지 않고 격자에도 맞추지 않습니다.
- `정육면체의 단면` 템플릿의 A–H도 꼭짓점에 고정되어 있어서 정육면체를 키우거나 돌리면 따라갑니다.

### 점 끌기

- 자유 점은 자기 높이의 수평면에서 움직입니다. 끄는 중에 **Shift**를 누르면 위아래로만 움직입니다.
  정면·옆면처럼 수평으로 볼 때는 화면과 나란히 움직입니다.
- 끄는 동안 바닥까지 내린 점선이 높이를 보여 주고, 격자 스냅은 움직이는 방향의 좌표에만 걸립니다.
- 꼭짓점·중심·선분 위에 놓으면 거기에 붙습니다. 구·평면·원판에는 실제로 닿을 때만 붙어서, 평면 위에
  떠 있는 점을 끌어도 평면에 달라붙지 않습니다. Shift로 내려서 닿게 하면 붙습니다.
- 다른 점 위에 놓으면 그 점과 합쳐지고, 끌던 점을 지나던 선분·면·표시는 그 점을 지나게 됩니다. 같은
  선분의 두 끝처럼 합치면 무너지는 점끼리는 합쳐지지 않습니다.
- 선분 위·구 위·평면 위의 점은 끌면 그 위에서만 움직입니다. 꼭짓점·중점처럼 고정된 점은 끌리지
  않으니, 옮기려면 속성 패널에서 **자유 점으로 풀기**를 누르세요.
- 고른 점은 점 자체가 손잡이입니다. X·Y·Z 화살표로 한 축을 따라 옮길 수도 있습니다.

## 작도

**작도** 도구는 고른 것을 기준으로 규칙을 가진 점을 세우고, 기준을 옮기면 점이 따라갑니다. 조건이
맞으면 단추가 초록으로 켜집니다.

| 도구       | 고를 것                                      | 새 점            |
| ---------- | -------------------------------------------- | ---------------- |
| 중점       | 점 두 개, 또는 선분 하나                     | M (다음은 N)     |
| 수선의 발  | 점 하나 + 평면·면·원판·선분 하나             | H                |
| 교점       | 선분 하나 + 평면·면·원판 하나                | P                |
| 중심       | 도형·면·선분 하나                            | O (면은 G, 선분은 M) |
| 선분 위    | 선분 하나 — 끌면 선분을 따라 움직임         | P                |
| 구 위      | 구 하나 — 끌면 구면을 따라 움직임           | P                |
| 평면 위    | 평면·원판 하나 — 끌면 그 위에서 움직임      | P                |

규칙이 있는 점은 속성 패널에서 비율·방위·고도 같은 값을 숫자로 바꿀 수 있고, **자유 점으로 풀기**로
규칙을 지우고 그 자리에 둘 수 있습니다. 평행해서 만나지 않는 교점처럼 계산할 수 없는 규칙은 만들 수 없습니다.

**선분**은 고른 점 두 개 이상을 차례로 잇고, 아무것도 고르지 않았다면 새 점 두 개로 만듭니다.
**면**은 고른 점 세 개 이상을 지나는 다각형입니다.

## 불리언

입체 두 개를 고르고 **합치기 · 빼기 · 교집합** 중 하나를 누릅니다. 먼저 고른 것이 A이고, 빼기는 A − B입니다.

- 결과는 장면 목록에 하나로 나오고, 재료는 그 아래에 `A`와 `∪ − ∩` 표시로 들어갑니다.
- 재료를 고르면 초록 점선 윤곽으로 보이고, 그대로 옮기거나 크기를 바꾸면 결과가 따라 바뀝니다.
  같은 자리를 여러 번 눌러도 재료에 닿습니다.
- 속성 패널에서 연산을 바꾸고, **A·B 바꾸기**, **풀기**(재료를 다시 따로 두기)를 할 수 있습니다.
- 결과를 지우면 재료도 지워집니다. 불리언 결과를 다시 재료로 쓸 수 있습니다.

## 표시: 각과 길이

- **각**: 점 세 개를 A → 꼭짓점 → B 순서로 고르거나, 한 점에서 만나는 선분 두 개를 고릅니다. 90°면
  직각 표시, 아니면 호를 그리고, 라벨이 비어 있으면 잰 각도(예: `30°`)를 씁니다.
- **길이**: 점 두 개나 선분 하나를 고릅니다. 두 끝을 잇는 점선 호를 그림 바깥쪽으로 그리고, 호 가운데를
  비워 그 자리에 정확한 값을 씁니다(`3`, `3/2`, `√3`, `√6/2`, `3√2` …). 속성의 **점선 호**를 끄면 선분 옆에 수치만 씁니다.

## 라벨

- 점은 A, B, C …, 평면은 α, β, γ … 순서로 이름이 붙습니다. 속성 패널에서 바꿉니다.
- 글자 뒤에 붙은 숫자는 아래 첨자가 됩니다: `S1` → S₁. `2.45` 같은 수는 그대로입니다.
- `√`로 근호, `/`로 분수를 씁니다: `√6/2`는 분자 √6, 분모 2인 세로 분수로 그려집니다.
- 라벨은 [upmath](https://upmath.me)가 LaTeX로 조판해 그림에 윤곽선으로 넣습니다. 한글처럼 LaTeX로
  쓸 수 없는 라벨과 조판을 받아 오는 동안의 라벨은 글자로 씁니다.
- 소문자·그리스 문자와 도형 이름은 이탤릭, 점 이름(대문자)과 수치는 정자입니다.
- 라벨은 끌어서 옮기고, 속성 패널의 **라벨 자리 되돌리기**로 자동 위치로 돌립니다.

## 면과 선분의 모양

- **평면·원판·면**의 **가림면**을 끄면 투명해집니다. 아무것도 가리지 않고, 테두리와 다른 도형을
  자르는 선만 그립니다.
- **선분**은 자동(가려지면 점선)·늘 점선(보조선)·늘 실선을 고르고, 끝에 화살촉을 달 수 있습니다.
- 기울인 직육면체도 정확한 도형으로 그려져 다른 도형과의 교선이 나옵니다.

## 장면 설정

아무것도 고르지 않으면 오른쪽에 나옵니다: 가려진 선(점선·지우기·실선), 선 굵기, 교선, 라벨,
점 표시, 바닥 격자(작업용, 저장되지 않음), 조명 채색(방위각·높이·주변광).

## 저장과 내보내기

| 메뉴                 | 내용                                                                   |
| -------------------- | ---------------------------------------------------------------------- |
| SVG 저장             | 화면의 선과 라벨 그대로. 채색을 켰다면 명암 이미지도 함께              |
| PNG                  | 2배 해상도 그림, 흰 바탕                                               |
| 장면 JSON            | 다시 열 수 있는 파일. 시점이 함께 저장됩니다(**열기**로 불러옴)       |
| 공유 링크 복사       | 장면과 시점을 압축해 주소 하나에 담음. 받는 사람은 열기만 하면 됨      |
| TypeScript 코드      | 라이브러리로 같은 선을 그리는 코드(라벨·점·표시는 빠짐)                |

- 작업 내용과 시점은 이 브라우저에 자동 저장됩니다. 다른 기기로 옮기려면 JSON이나 공유 링크를 쓰세요.
- 다크 모드에서는 화면만 어둡게 바뀌고, 내보낸 SVG·PNG는 늘 흰 바탕의 먹색 선입니다.
- **템플릿**에서 시험지 단골 그림(구와 평면, 정사면체와 수선의 발, 좌표공간, 구멍 뚫린 구 …)으로 시작할 수 있습니다.
  지금 장면은 실행 취소(`⌘Z`)로 되돌릴 수 있습니다.
