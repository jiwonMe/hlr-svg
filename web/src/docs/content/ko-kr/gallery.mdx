[예제 갤러리](/docs/ko-kr/examples)의 모든 그림은 브라우저에서 hlr로 그때그때 렌더링됩니다.
끌어서 돌리고, 휠로 확대하고, 가려진 선의 표현(점선·지우기·실선)을 바꿔 볼 수 있습니다.
예제마다 같은 그림을 그리는 전체 코드가 함께 있어 복사해 바로 실행할 수 있습니다.

## 시험지 그림

| 예제                     | 볼 것                                                    |
| ------------------------ | -------------------------------------------------------- |
| 좌표공간의 평면과 좌표축 | 면이 좌표축을 가려 축의 뒷부분이 점선이 되는 모습       |
| 정육면체의 단면          | 모서리와 단면 삼각형, 점 이름                            |
| 원기둥과 45° 평면        | 평면이 원기둥을 자르는 타원(교선)                        |
| 구에 접하는 세 구        | 여러 구와 두 평면이 서로 가리는 관계, 평면 단면         |
| 구와 두 평면의 단면      | 구를 지나는 두 평면과 단면의 원                          |

## 라이브러리 기능

| 예제                    | 볼 것                                                   |
| ----------------------- | ------------------------------------------------------- |
| 기본 도형 네 가지       | 구·원기둥·원뿔·직육면체의 윤곽선과 서로 만나는 교선      |
| 원뿔과 평면의 교선      | 평면의 기울기에 따라 원·타원·포물선·쌍곡선이 되는 단면   |
| 무작위 도형 (seed 고정) | 같은 seed로 같은 장면을 다시 만드는 방법                 |
| OBJ·STL 메시 불러오기   | 파일을 끌어 놓아 메시의 특징선을 숨은선으로 그리기     |

면 채색이 있는 예제에서는 조명 방향과 주변광을 바꿔 볼 수 있습니다. 채색은
[면 채색](/docs/ko-kr/shading) 문서의 표면 버퍼 API로 만듭니다.
