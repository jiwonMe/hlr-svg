AI 코딩 도구는 최신 라이브러리를 잘 모르거나 API를 지어내곤 합니다. 이 사이트는
[llms.txt](https://llmstxt.org) 규칙에 따라 모델이 읽기 좋은 마크다운 문서를 함께 제공합니다.
문서를 고칠 때마다 사이트 빌드에서 자동으로 다시 만들어집니다.

## 제공하는 파일

| 주소                                         | 내용                                                    |
| -------------------------------------------- | ------------------------------------------------------- |
| `https://hlr.js.org/llms.txt`                | 요약, 꼭 지킬 규칙, 문서 목록과 링크                    |
| `https://hlr.js.org/llms-full.txt`           | 영어 문서 전체를 한 파일로                              |
| `https://hlr.js.org/llms-full.ko.txt`        | 한국어 문서 전체를 한 파일로                            |
| `https://hlr.js.org/docs/ko-kr/<문서>.md`    | 문서 한 쪽의 마크다운 (예: `/docs/ko-kr/booleans.md`)   |
| `https://hlr.js.org/docs/en-us/<문서>.md`    | 영어판                                                  |

모든 문서 위쪽의 **Markdown 복사** 단추는 그 쪽의 마크다운을 클립보드에 넣습니다.

## 쓰는 방법

- **채팅(ChatGPT, Claude 등)**: `llms-full.txt`를 내려받아 첨부하거나, 내용을 붙여 넣은 뒤
  질문하세요. 웹을 읽을 수 있는 모델이라면 주소만 줘도 됩니다.
- **Cursor**: 설정의 Docs에 `https://hlr.js.org/llms-full.txt`를 추가하고, 질문할 때 `@Docs`로 부릅니다.
- **Claude Code, Codex 같은 에이전트**: 프로젝트 지침 파일(`CLAUDE.md`, `AGENTS.md` 등)에
  "hlr을 쓸 때는 https://hlr.js.org/llms-full.txt 를 먼저 읽을 것"이라고 적어 두세요.
- **한 가지 주제만**: 해당 문서의 `.md`나 **Markdown 복사**가 짧고 정확합니다.

## 질문 예시

```text
아래 hlr 문서를 참고해서, 반지름 2인 구가 평면 위에 놓인 그림을 그리는 TypeScript 코드를 써 줘.
직교 카메라, 640×480, 가려진 선은 점선. 구의 중심에 점 O와 라벨을 덧그려 줘.
문서에 없는 API는 쓰지 말고, 확실하지 않으면 그렇다고 말해 줘.

[llms-full.txt 내용]
```

## 모델이 자주 틀리는 것

`llms.txt` 맨 앞에도 같은 내용이 있습니다.

- 패키지 이름은 `hlr`이고 ES 모듈입니다: `import { Scene } from "hlr"`.
- 모든 도형의 첫 인자는 장면 안에서 고유한 id 문자열입니다.
- `Cylinder`는 `(id, base, axis, height, radius, caps)`이고 `caps`는 `"both"` 또는 `"none"`입니다.
  `Cone`의 축은 꼭짓점에서 **밑면 쪽**을 향합니다.
- 카메라는 `Camera.from({ kind: "orthographic" | "perspective", … })`이고, `aspect`는 SVG의
  `width / height`와 같아야 합니다. 직교는 `halfHeight`, 원근은 `fovYRad`(라디안)를 씁니다.
- `Scene`에는 `remove`가 없고 `removeById(id)`와 `clear()`가 있습니다.
- 벡터 길이는 `Vec3.len`, `Vec3.lenSq`입니다(`length`가 아님).
- 평면과 원판은 양면 모두 불투명합니다. 투명한 평면은 장면에 넣지 말고 `curves`와 `ownedCurves`로 그립니다.
- 렌더러는 글자를 그리지 않습니다. 라벨은 `camera.projectToSvg`로 좌표를 얻어 SVG에 덧붙입니다.
- `SvgRenderer`의 `width`·`height`는 생성자에서만 정합니다.
