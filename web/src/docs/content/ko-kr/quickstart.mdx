## 설치

`hlr`은 ES 모듈로 배포되는 TypeScript 라이브러리입니다. 의존성이 없고, Node.js 20 이상과
번들러(Vite, webpack, esbuild 등)를 쓰는 브라우저 앱에서 똑같이 동작합니다.

```bash
pnpm add hlr
# 또는 npm install hlr / yarn add hlr
```

> 패키지는 `"type": "module"`입니다. CommonJS(`require`)에서는 `await import("hlr")`로 불러오세요.

## 첫 그림: 평면 위의 구

수학 시험지에 자주 나오는 그림 하나를 그려 봅니다. 평면 α 위에 구가 걸쳐 있고,
평면 아래로 들어간 부분과 구 뒤쪽의 선은 점선이 됩니다.

```typescript
import { writeFileSync } from "node:fs";
import { Camera, PlaneRect, Scene, Sphere, SvgRenderer, Vec3 } from "hlr";

// 1. 장면: 도형마다 고유한 id를 붙입니다.
const scene = new Scene([
  new Sphere("S", new Vec3(0, 1, 0), 1.5),
  new PlaneRect(
    "alpha",
    new Vec3(0, 0, 0), // 중심
    new Vec3(0, 1, 0), // 법선 (위쪽)
    new Vec3(1, 0, 0), // 가로 방향
    3, // 가로 절반 길이
    3, // 세로 절반 길이
  ),
]);

// 2. 카메라: 시험지 그림은 평행선이 평행하게 보이는 직교 투영이 잘 어울립니다.
const width = 640;
const height = 480;
const camera = Camera.from({
  kind: "orthographic",
  position: new Vec3(6, 5, 8),
  target: new Vec3(0, 0.6, 0),
  up: new Vec3(0, 1, 0),
  halfHeight: 3, // 화면 세로의 절반이 월드 좌표로 3
  aspect: width / height,
  near: 0.1,
  far: 100,
});

// 3. 렌더링: 결과는 SVG 문자열입니다.
const renderer = new SvgRenderer({ width, height });
const svg = renderer.render(scene, camera);

writeFileSync("figure.svg", svg);
```

`node figure.mjs`로 실행하면 `figure.svg`가 생깁니다. 그림에는 다음 선이 들어 있습니다.

- **구의 윤곽선**: 카메라에서 본 구의 테두리. 평면 아래로 들어간 부분은 평면에 가려 점선입니다.
- **평면의 테두리**: 사각형 네 변. 구 뒤로 지나는 부분이 점선입니다.
- **교선**: 평면이 구를 자르는 원. 구 뒤쪽 절반이 점선입니다.

이 세 종류의 선을 누가 만들었는지, 어떻게 보이는 부분과 가려진 부분으로 나뉘는지는
[핵심 개념](/docs/ko-kr/concepts)에서 설명합니다.

## 브라우저에서 보기

결과가 문자열이므로 DOM에 그대로 넣으면 됩니다.

```typescript
const svg = renderer.render(scene, camera);
document.querySelector("#figure")!.innerHTML = svg;
```

시점을 바꿀 때마다 `Camera.from`으로 카메라를 새로 만들고 같은 `SvgRenderer`로 다시
그리세요. 렌더러는 카메라와 무관한 계산(교선)을 기억해 두기 때문에 다시 그리기가 빠릅니다.

## 선 모양 바꾸기

`style`로 보이는 선과 가려진 선을 따로 꾸밉니다. 아래는 시험지 그림에 가까운 설정입니다.

```typescript
const renderer = new SvgRenderer({
  width,
  height,
  background: false, // 흰 바탕 사각형을 넣지 않음
  style: {
    strokeVisible: "#0a0a0a",
    strokeHidden: "#0a0a0a",
    strokeWidthVisible: 1.4,
    strokeWidthHidden: 1.1,
    dashArrayHidden: "3.2 2.6",
    opacityHidden: 0.9,
  },
});
```

가려진 선을 아예 지우려면 `opacityHidden: 0`, 실선으로 그리려면 `dashArrayHidden: "none"`을
쓰세요. 모든 옵션은 [렌더링과 스타일](/docs/ko-kr/rendering)에 있습니다.

## 여러 도형

도형을 여러 개 넣으면 서로 가리는 관계와 만나는 교선이 자동으로 계산됩니다.

```typescript
import { BoxAabb, Cone, Cylinder, Scene, Sphere, Vec3 } from "hlr";

const scene = new Scene([
  new Sphere("ball", new Vec3(-1.6, 1, 0), 1),
  new Cylinder("can", new Vec3(0, 0, 0), new Vec3(0, 1, 0), 2, 0.7),
  new Cone("cone", new Vec3(1.6, 2, 0), new Vec3(0, -1, 0), 2, 0.9),
  new BoxAabb("box", new Vec3(-0.5, 0, 1), new Vec3(0.5, 1, 2)),
]);
```

`Cylinder`는 밑면 중심·축 방향·높이·반지름, `Cone`은 꼭짓점·축 방향(꼭짓점에서 밑면 쪽)·높이·밑면
반지름을 받습니다. 도형별 자세한 설명은 [도형](/docs/ko-kr/primitives)을 보세요.
