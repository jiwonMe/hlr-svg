모든 이름은 패키지 최상위에서 가져옵니다.

```typescript
import { Scene, Camera, SvgRenderer, Sphere, Vec3 } from "hlr";
import type { RenderOptions, SvgStyle, CubicBezier3 } from "hlr";
```

## 장면

### Scene

```typescript
class Scene {
  constructor(primitives?: readonly Primitive[]);
  readonly primitives: readonly Primitive[];
  add(...primitives: Primitive[]): this;
  removeById(id: string): this;
  clear(): this;
  toRaycastScene(camera: Camera, profiler?: Profiler, preparedGeometry?: boolean): RaycastScene;
}
```

`toRaycastScene`은 그 카메라에 대한 광선 검사용 장면을 만듭니다. 돌려받은 객체는 다음 두 메서드를 씁니다.

```typescript
visibleAtPoint(p: Vec3, opts?: { eps?: number; ignorePrimitiveIds?: readonly string[] }): boolean;
raycastClosest(
  ray: Ray,
  opts?: { tMin?: number; tMax?: number; ignorePrimitiveId?: string; ignorePrimitiveIds?: readonly string[] },
): Hit | null;
```

`preparedGeometry: true`는 기본 도형에 빠른 교차 커널을 미리 준비합니다. 도형이 바뀌면 다시 만드세요.

## 카메라

### Camera

```typescript
class Camera {
  static from(params: CameraParams): Camera;
  readonly kind: "perspective" | "orthographic";
  readonly position: Vec3;
  readonly target: Vec3;
  readonly up: Vec3;
  readonly aspect: number;
  readonly near: number;
  readonly far: number;
  readonly fovYRad?: number; // 원근
  readonly halfHeight?: number; // 직교
  readonly forward: Vec3; // 시선 방향 단위 벡터
  readonly view: Mat4;
  readonly proj: Mat4;
  readonly viewProj: Mat4;
  readonly viewProjInv: Mat4;
  projectToNdc(p: Vec3): { x: number; y: number; z: number };
  projectToSvg(p: Vec3, width: number, height: number): { x: number; y: number; z: number };
  screenToRay(x: number, y: number, width: number, height: number): Ray;
}

type CameraParams =
  | { kind: "perspective"; position: Vec3; target: Vec3; up: Vec3; fovYRad: number; aspect: number; near: number; far: number }
  | { kind: "orthographic"; position: Vec3; target: Vec3; up: Vec3; halfHeight: number; aspect: number; near: number; far: number };
```

### SvgRenderer

```typescript
class SvgRenderer {
  constructor(options: Omit<RenderOptions, "curves" | "ownedCurves">);
  render(scene: Scene, camera: Camera, overrides?: Partial<Omit<RenderOptions, "width" | "height">>): string;
}

type RenderOptions = {
  width: number;
  height: number;
  background?: boolean; // 기본 true: 흰 사각형
  style?: Partial<SvgStyle>;
  include?: RenderInclude;
  hlr?: Partial<HlrParams>;
  intersections?: Partial<IntersectionParams>;
  mesh?: Partial<MeshRenderParams>;
  curves?: readonly CubicBezier3[];
  ownedCurves?: readonly OwnedIntersectionCubic3[];
  profiler?: Profiler;

```

각 옵션의 뜻과 기본값은 [렌더링과 스타일](/docs/ko-kr/rendering)에 있습니다.

```typescript
function renderToSvg(scene: Scene, camera: Camera, opts: RenderOptions): string;
function renderPrimitivesToSvg(primitives: readonly Primitive[], camera: Camera, opts: RenderOptions): string;

const DEFAULT_HLR_PARAMS: HlrParams; // samples 192, coarseSamples 0, refineIters 22, epsVisible 2e-4, cutEps 1e-6, minSegLenSq 1e-6
const DEFAULT_INTERSECTION_PARAMS: IntersectionParams; // angularSamples 160, useBezierFit true, fitMode "stitchThenFit"
const DEFAULT_MESH_PARAMS: MeshRenderParams; // creaseAngleDeg 30

type HlrParams = { samples: number; coarseSamples?: number; refineIters: number; epsVisible: number; cutEps: number; minSegLenSq: number };
type IntersectionParams = { angularSamples: number; useBezierFit?: boolean; fitMode?: "perRun" | "stitchThenFit" };
type MeshRenderParams = { creaseAngleDeg: number };
type RenderInclude = CurveInclude & { intersections?: boolean };
type CurveInclude = { silhouettes?: boolean; rims?: boolean; borders?: boolean; boxEdges?: boolean; meshEdges?: boolean; csg?: boolean };
```

### Primitive, Ray, Hit

```typescript
interface Primitive {
  readonly id: string;
```

### 해석적 도형

```typescript
class Sphere { constructor(id: string, center: Vec3, radius: number) }

class Cylinder {
  constructor(id: string, base: Vec3, axis: Vec3, height: number, radius: number, caps?: CylinderCaps);
  readonly axis: Vec3; // 정규화됨
}
type CylinderCaps = "none" | "both"; // 기본 "both"

class Cone {
  constructor(id: string, apex: Vec3, axis: Vec3, height: number, baseRadius: number, cap?: ConeCaps);
  readonly axis: Vec3; // 꼭짓점 → 밑면, 정규화됨
}
type ConeCaps = "none" | "base"; // 기본 "base"

class BoxAabb { constructor(id: string, min: Vec3, max: Vec3) }

class OrientedBox {
  constructor(id: string, center: Vec3, halfSize: Vec3, axisX: Vec3, axisY: Vec3);
  readonly axes: readonly [Vec3, Vec3, Vec3]; // 정규 직교, z = x × y
  toLocal(p: Vec3): Vec3;
  corners(): Vec3[]; // 8개
  edges(): [Vec3, Vec3][]; // 12개
  faces(tag?: string): PlaneRect[]; // 6개, id는 `${id}:${tag}:face:±x|±y|±z`
}

class PlaneRect {
  constructor(id: string, center: Vec3, normal: Vec3, uHint: Vec3, halfWidth: number, halfHeight: number);
  readonly normal: Vec3; // 단위
  readonly u: Vec3; // uHint를 평면에 투영해 정규화
  readonly v: Vec3; // normal × u
}

class Disk { constructor(id: string, center: Vec3, normal: Vec3, radius: number) }
```

생성자 인자는 같은 이름의 읽기 전용 속성으로도 공개됩니다(`sphere.center`, `cone.baseRadius` 등).

### Csg

```typescript
class Csg {
  constructor(id: string, operation: CsgOperation, a: CsgSolid, b: CsgSolid);
  classify(p: Vec3, tolerance: number): CsgClass; // -1 안, 0 표면, 1 밖
  leaves(): CsgLeaf[]; // 재료 도형, 깊이 우선
  size(): number; // 가장 큰 재료의 크기
}
type CsgOperation = "union" | "subtract" | "intersect";
type CsgLeaf = Sphere | Cylinder | Cone | BoxAabb | OrientedBox;
type CsgSolid = CsgLeaf | Csg;
type CsgClass = -1 | 0 | 1;
type CsgSpan = { start: { t: number; normal: Vec3 }; end: { t: number; normal: Vec3 } };

const CSG_TOLERANCE: number; // 3e-3, 재료 크기에 곱해 쓰는 표면 판정 허용오차
function csgSpans(solid: CsgSolid, ray: Ray): CsgSpan[]; // 광선이 입체 안에 있는 구간
function leafDistance(leaf: CsgLeaf, p: Vec3): number; // 부호 있는 거리(안쪽 음수)
function csgBoundaryCurves(csg: Csg, camera: Camera): CubicBezier3[];
function csgCurvesForPrimitives(primitives: readonly Primitive[], camera: Camera): CubicBezier3[];
```

캐시판은 결과를 얼려(freeze) 돌려줍니다. 고쳐 쓰려면 캐시 없는 함수를 쓰세요. 서명이
`undefined`인 장면(직접 만든 도형 등)은 캐시하지 않습니다.
